# Taste Skill (Flutter Adaptation)

When designing screens and UI components:
1. Infer the brief's tone and audience before styling.
2. Maintain high design variance (custom components, editorial hierarchy, asymmetrical badges).
3. Implement tactile animations (spring curves, scale feedback on taps, heart bursts).
4. Enforce disciplined visual density: generous whitespace, 1px subtle borders, no muddy drop shadows or generic purple gradients.
5. Use real high-resolution media and realistic copy.
